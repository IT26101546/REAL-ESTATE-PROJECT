# Member 3 frontend source map

JSX/CSS pages: `CreateBookingPage`, `MyBookingsPage`, `BookingDetailsPage`,
`ManageBookingsPage`, `PaymentPage`, `PaymentHistoryPage`, and `ReceiptPage` in
`frontend/src/pages/Member3_BookingPayment/`. API calls are in
`frontend/src/api/bookingPaymentApi.js`.

The pages include field validation, submission loading indicators, API error
display, confirmation messages, history views, and receipt rendering.
