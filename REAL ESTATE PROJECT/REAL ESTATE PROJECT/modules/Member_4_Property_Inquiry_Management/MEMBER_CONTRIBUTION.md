# Member 4 — Property Inquiry Management

Owns the buyer-to-seller question workflow, inquiry history, edit/delete flow,
and seller replies. JSX/CSS, Java layers, DTOs, table definition, sample data,
and request reference are provided through this module’s child folders. The
module joins the shared application; start the common backend and frontend rather
than attempting to run an isolated duplicate server: from `../../backend` run
`mvn spring-boot:run`, then from `../../frontend` run `npm install` and
`npm run dev`.
